\begin{abstract}
Instruction-conditioned music editing is the natural next step after text-to-audio generation, yet symbolic benchmarks still emphasize either theory question answering over score images or audio remixing without MIDI-native preservation checks. We introduce \textbf{MIDI-Instruct}, a benchmark of source MIDI, natural-language instructions, and machine-checkable edit specifications. Each item is scored on two independent axes: \edit{} (did the requested transformation occur?) and \preserve{} (were the item's declared preservation constraints satisfied?). A companion \textbf{MIDI-Reason} track evaluates structured edit plans separately from emitted MIDI files. Version~0.1 provides 300 unique-gold items from programmatic multi-track seeds; version~0.2 extends the same operator families to 955 items from 200 MidiCaps/Lakh compositions with composition-level splits. On the v0.2 held-out test split (180 items, 45 compositions), a greedy Llama-3.2-1B plan-then-execute baseline obtains 0.59 joint pass rate, 0.633 \edit{}, 0.658 \preserve{}, and 0.622 exact plan match. It solves tempo scaling perfectly and track muting reliably, but transposition and program changes remain difficult: 26\% of items produce no valid output, mostly from truncated or malformed JSON plans. Programmatic controls separate metric axes on v0.2 (copy-source \preserve{} 1.0 but joint 0.02; wrong-transform joint 0) and reach oracle joint 1.0 on the synthetic pilot. These results show that file validity, requested change, preservation, and plan correctness capture distinct failure modes. We release the dataset generator, programmatic grader, reference baselines, and evaluation harness.
\end{abstract}
