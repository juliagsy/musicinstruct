\begin{abstract}
Instruction-conditioned music editing is the natural next step after text-to-audio generation, yet symbolic benchmarks still emphasize either theory question answering over score images or audio remixing without MIDI-native preservation checks. We introduce \textbf{MIDI-Instruct}, a benchmark of source MIDI, natural-language instructions, and machine-checkable edit specifications. Each item is scored on two independent axes: \edit{} (did the requested transformation occur?) and \preserve{} (were the item's declared preservation constraints satisfied?). A companion \textbf{MIDI-Reason} track evaluates structured edit plans separately from emitted MIDI files. Version~0.1 contains 300 unique-gold items synthesized from multi-track seeds via five verifiable transforms: transpose, tempo and velocity scaling, track muting, and program change. On the 50-item held-out test split, a greedy Llama-3.2-1B plan-then-execute baseline obtains 0.44 joint pass rate, 0.467 \edit{}, 0.693 \preserve{}, and 0.20 exact plan match. It solves muting and tempo scaling but fails all program changes and velocity edits, while 28\% of items produce no valid output. These results show that file validity, requested change, preservation, and plan correctness capture distinct failure modes. We release the dataset generator, programmatic grader, reference baselines, and evaluation harness.
\end{abstract}
