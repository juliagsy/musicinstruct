\section{Dataset construction}

\subsection{Seeds}

Version~0.1 uses 12 programmatic multi-track seeds (piano, bass, drums; four bars each) written in CC0-1.0 synthetic form. Each seed defines a \texttt{composition\_id}; all derived items inherit the same split assignment to prevent leakage.

\subsection{Splits}

Seeds 0--7 $\to$ train, 8--9 $\to$ validation, 10--11 $\to$ test. Future releases may add licensed corpora (Mutopia, Lakh subsets) with the same split policy.

\subsection{Scale}

The generator emits items from the Cartesian product of seeds, operator parameters, and instruction templates. Full generation yields 336 items: 192 transpose (8 semitone steps $\times$ 2 phrasings), 36 velocity, 36 tempo, 24 mute, and 48 program change. The released pilot trims to 300 items by proportional sampling across operator families while preserving split assignments by \texttt{composition\_id}.

\subsection{Reproducibility}

\begin{verbatim}
musicinstruct generate-pilot --output-dir data/pilot --target 300
musicinstruct validate data/pilot/pilot.jsonl
musicinstruct self-test data/pilot/pilot.jsonl
\end{verbatim}

Self-test scores gold MIDI against itself; joint pass rate should be 1.0, validating the grader before model experiments.
