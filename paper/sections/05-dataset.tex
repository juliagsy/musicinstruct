\section{Dataset construction}

\subsection{Synthetic pilot (v0.1)}

\paragraph{Seeds.}
Version~0.1 uses 12 programmatic multi-track seeds (piano, bass, drums; four bars each) generated by the toolkit and distributed under the repository license. Each seed defines a \texttt{composition\_id}; all derived items inherit the same split assignment to prevent leakage.

\paragraph{Splits.}
Seeds 0--7 $\to$ train, 8--9 $\to$ validation, 10--11 $\to$ test.

\paragraph{Scale.}
The generator emits items from the Cartesian product of seeds, operator parameters, and instruction templates. Full generation yields 336 items; the released pilot trims proportionally within each composition so every seed remains represented. Its 300 items comprise 168 transpose, 24 velocity, 36 tempo, 24 mute, and 48 program-change examples, split into 200 train, 50 validation, and 50 test items. The pilot test set contains 50 items from two compositions only; we use it primarily to validate the grader and programmatic controls before reporting model numbers on real MIDI.

\subsection{Real seeds (v0.2)}

\paragraph{Source corpus.}
Version~0.2 filters MidiCaps~\cite{midicaps2024} metadata against a local Lakh MIDI (\texttt{lmd\_full}) tree. Seeds must pass track-count, duration, and pitch-range filters; near-duplicate compositions are clustered by MD5 prefix so that all items from one cluster share a split. Composition IDs take the form \texttt{lmd\_<prefix>}. Items record \texttt{source=midicaps} and \texttt{license=CC-BY-4.0}. MidiCaps \texttt{test\_set} clusters are restricted to the benchmark test split.

\paragraph{Scale and splits.}
Generation from 200 accepted compositions yields 955 unique-gold items: 645 train (129 compositions), 130 validation (26 compositions), and 180 test (45 compositions). Train and validation retain the full operator mix per composition, including multiple transpose variants. Test is subsampled after generation to at most six items per composition and one random variant per \texttt{op\_family}, reducing correlated items from the same source file. The released v0.2 test split contains four operator families---transpose, tempo scale, track mute, and program change---with 45 items each and exactly four items per composition.

\paragraph{Reproducibility.}
\begin{verbatim}
musicinstruct generate-pilot --output-dir data/pilot --target 300
musicinstruct generate-real --lakh-root /path/to/lmd_full \
  --output-dir data/v0.2 --target 1000 --seed-limit 500 \
  --test-max-per-composition 6 --test-subsample-seed 0
musicinstruct validate data/v0.2/manifest.jsonl
musicinstruct self-test data/v0.2/manifest.jsonl
\end{verbatim}

Self-test scores gold MIDI against itself; joint pass rate should be 1.0, validating the grader before model experiments.
