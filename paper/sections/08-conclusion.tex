\section{Conclusion}

MIDI-Instruct defines instruction-conditioned symbolic music editing as a benchmarkable task with dual edit and preserve metrics, a separate MIDI-Reason plan track, and an open dataset generator spanning synthetic pilot seeds and real MidiCaps/Lakh compositions. On v0.2 real MIDI (180 test items, 45 compositions), programmatic controls confirm that copy-source and wrong-transform stay near-zero joint while the oracle reaches 0.933---surfacing predicate edge cases on diverse real files that the synthetic pilot oracle (joint 1.0) does not expose. A Llama-3.2-1B plan-then-execute baseline reaches 0.589 joint success with 0.622 plan match---strong tempo and muting performance but systematic transposition and program-change failures, plus 26\% invalid outputs from truncated JSON. These operator-level differences would be obscured by validity, preservation, or plan accuracy alone. By grading emitted MIDI with programmatic predicates rather than LLM judges and retaining failed attempts in the denominator, the benchmark supports reproducible diagnosis of future text-to-MIDI systems, editing models, and tool-augmented agents. The next release should tighten real-file predicate coverage, add constraint-gold instructions, restore velocity in subsampled test sets, and compare constrained decoding and tool-augmented runners.
